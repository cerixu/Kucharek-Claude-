# Kucharzyna 👨‍🍳

Prywatny notatnik szefa kuchni na iPhone'a. Instalowalna aplikacja PWA, działa bez internetu, bez kont, reklam, śledzenia i płatnych API.

## Funkcje

- Receptury, wyszukiwarka, kategorie, filtry, sortowanie i ulubione.
- Edytor receptur z sekcjami, składnikami, krokami, zdjęciem i własnymi uwagami.
- Tryb GOTUJĘ z checkboxami i minutnikiem.
- Przeliczanie receptur i procenty piekarskie.
- Kalkulatory pizzy/ciasta, procentów i food cost.
- Lista zakupów, import przepisów i kopia JSON.
- Tryb Pro i Amator oraz jasny/ciemny/auto.

## Uruchomienie

Brak bundlera i zależności. To czyste moduły ES. Service worker i instalacja PWA wymagają HTTPS albo localhost.

## GitHub Pages

Ustaw Settings → Pages → Deploy from a branch → main → / (root).
